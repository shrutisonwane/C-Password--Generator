# C Password Generator

My first C programming project! 🎉

## About
A simple password generator written in C that generates a random password using uppercase letters, lowercase letters, and digits.

## Features
- User chooses the password length.
- Generates random characters.
- Uses C standard libraries.

## Technologies Used
- C Programming
- GCC Compiler
- Git and GitHub

## How to Run

1. Compile the program:
   gcc passwordgenerator.c -o passwordgenerator

2. Run the program:

   On Windows:
   .\passwordgenerator.exe

   On Linux/macOS:
   ./passwordgenerator
